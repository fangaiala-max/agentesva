What are agent skills?

An agent skill is a small folder an AI coding agent can load on demand. It holds a SKILL.md file, with a short description of when to use it and step-by-step instructions, plus any scripts the agent should run. Claude Code reads every skill's description at start-up; when your request matches one, it pulls in the full instructions and calls the scripts. Cursor and other agents that support the SKILL.md format work the same way.

Skills turn "the agent could probably figure this out" into "the agent does this the same reliable way every time". Each skill in these packs is a SKILL.md plus a small Python command-line tool that calls the provider's official API directly. Nothing is proxied through a third party, and you can read every line.

How to install Claude Code skills
Unzip the pack you downloaded from Gumroad.
Run the installer: ./install.sh copies each skill into ~/.claude/skills. For another agent, set the folder: SKILLS_DIR=/path/to/skills ./install.sh. Existing skills are never overwritten.
Add your keys: copy .env.example to .env and fill in only the services you use. The included QUICKSTART walks through each one.
Ask in plain English. The agent picks the right skills, and you get real results from your own accounts.

Requirements: Python 3.10+. Some skills need their pip requirements or a provider CLI; the film-maker skill needs ffmpeg.
